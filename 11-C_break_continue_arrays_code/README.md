# C Break & Continue, Arrays, and Multidimensional Arrays Examples

This repository/folder contains executable C programs based on the **Break & Continue, Arrays, Array Size, Array Loop, Multidimensional Arrays (C_Note-07.pdf)** exam revision note topic.

## Files Included
1. `01_break_example.c` - Using `break` statement to terminate loops early.
2. `02_continue_example.c` - Using `continue` statement to skip specific loop iterations.
3. `03_break_continue_combined.c` - Practical usage of `break` and `continue` together with arrays.
4. `04_array_basics.c` - Array declaration, indexing, element modification, and fixed-size arrays.
5. `05_array_size_sizeof.c` - Memory size calculation using `sizeof` and computing element length.
6. `06_array_loops.c` - Looping through arrays using fixed vs dynamic `sizeof` length practices.
7. `07_array_real_life.c` - Practical applications (computing average age and finding minimum value).
8. `08_multidimensional_arrays.c` - 2D & 3D arrays declaration, element access, modification, and nested loops.
