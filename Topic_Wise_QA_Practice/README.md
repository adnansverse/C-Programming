# Topic-Wise Q&A Practice

Topic-wise practice questions with solved C programs, covering everything
from the beginning (00-Syntax) up to Multidimensional Arrays (15).

Each day, one topic is added: the questions are written at the top of the
`.c` file as comments, and the solution follows in the same file.
Every solution is compile-tested before it is pushed.
