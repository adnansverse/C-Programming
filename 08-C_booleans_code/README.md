# C Booleans Code Examples

This repository/folder contains executable C programs based on the **C Boolean** exam note topic.

## Files Included
1. `01_boolean_variables.c` - Declaring and printing boolean variables using `<stdbool.h>`.
2. `02_comparing_values.c` - Comparing values and variables using relational operators.
3. `03_storing_comparison.c` - Storing comparison results into boolean variables.
4. `04_logical_operators.c` - Using `&&`, `||`, and `!` logical operators.
5. `05_real_life_voting.c` - Real-life voting eligibility example with `if...else`.
6. `06_truthy_falsy.c` - Demonstrating 0 (false) and non-zero (true) concept in C.
7. `07_practice_questions.c` - Self-assessment practice code.
