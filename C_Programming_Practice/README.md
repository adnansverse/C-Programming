# C Programming Practice

This repository contains C programming practice problems and their solutions, organized for easy navigation and GitHub portfolio presentation.

## Included Programs:

1. **`01_circle_perimeter_and_area.c`**
   - Calculates the perimeter and area of a circle with a radius of 6 units.
2. **`02_multiple_variables_operations.c`**
   - Demonstrates operations across various standard C data types (`int`, `long`, `short`, `float`, `double`, `char`, `unsigned long`), implicit type conversion with ASCII characters, and type casting.

## How to Compile and Run:

```bash
# Compile
gcc 01_circle_perimeter_and_area.c -o circle
gcc 02_multiple_variables_operations.c -o multi_var

# Run
./circle
./multi_var
```
