# Matrix Calculator (C Project)

A small console project built step by step to practice 2D arrays,
nested loops and functions in C.

## Build Plan

- [x] **Step 1:** Take a matrix as input and display it — `01_matrix_input_display.c`
- [ ] **Step 2:** Add two matrices and subtract two matrices
- [ ] **Step 3:** Multiply two matrices
- [ ] **Step 4:** Find the transpose of a matrix
- [ ] **Step 5:** Add a menu so the user can choose an operation, and polish the final program

## Concepts Practised

- 2D arrays (from `15_Multidimensional_Arrays`)
- Nested loops
- `scanf` / `printf` formatting
- Later steps: functions and switch-case menus

## How to Run

```bash
gcc 01_matrix_input_display.c -o matrix
./matrix
```

Example (2 rows x 3 columns, elements 1-6):

```
Your matrix is:
   1   2   3
   4   5   6
```
