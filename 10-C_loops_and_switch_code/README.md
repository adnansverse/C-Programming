# C Loops & Switch Statement Code Examples

This repository/folder contains executable C programs based on the **Loops & Switch Statement (C_Note-06.pdf)** exam revision note topic.

## Files Included
1. `01_switch_statement.c` - Switch statements, default cases, and fall-through behavior.
2. `02_while_loop.c` - Standard `while` loop, countdown, and initial false conditions.
3. `03_do_while_loop.c` - `do/while` loop and demonstrating execution at least once.
4. `04_while_loop_real_life.c` - Practical examples (even numbers, reversing a number, Yatzy game).
5. `05_for_loop.c` - Standard `for` loop, sum of numbers, even numbers, and countdown.
6. `06_nested_loop.c` - Nested loops and matrix/multiplication table generation.
7. `07_for_loop_real_life.c` - Real-life for loop applications (counting by tens, powers of 2, multiplication table).
