# C If...Else Code Examples

This repository/folder contains executable C programs based on the **C If...Else** exam note topic.

## Files Included
1. `01_if_statement.c` - Basic `if` statement examples.
2. `02_if_else_statement.c` - `if...else` usage with variables and booleans.
3. `03_else_if_statement.c` - Multiple conditions with `else if`.
4. `04_ternary_operator.c` - Short hand `if...else` (Ternary operator `?:`).
5. `05_nested_if.c` - `if` statements inside another `if`.
6. `07_logical_operators.c` - Logical operators (`&&`, `||`, `!`) with real-life access control example.
7. `07_switch_statement.c` - Quick overview of `switch` statement.
8. `08_real_life_examples.c` - Door code, even/odd, temperature, and number checking examples.
